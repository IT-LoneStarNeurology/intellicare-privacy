IntelliCare Privacy Policy

Last updated: September 28, 2026

IntelliCare is an internal tool built for LoneStar Neurology's own use and is not available to the public.

What the browser extension does

The extension reads the patient chart open in eClinicalWorks and sends that data only to a companion application running on the same computer (127.0.0.1). It does not send data to any third-party server, and it does not run on any website other than LoneStar Neurology's eClinicalWorks instance.

What the companion application does

The local companion application uses the chart data to power on-screen documentation assistance. Depending on which features are enabled for a given user, structured, non-patient-identifying summaries (such as a provider name, a rule ID, or a count) may be sent to LoneStar Neurology's own private cloud infrastructure to support practice-level compliance review and analytics. Patient names and clinical narrative text are encrypted before leaving the local network and are only ever decrypted for an authorized manager or administrator reviewing a specific flagged record.

Data retention

Chart data stays on the local computer unless a specific rule requires a record to be created for practice review, in which case only that record (not the full chart) is retained.
